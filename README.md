# CarProtect

אפליקציה לבדיקת סטטוס רכב בישראל — צילום לוחית וקבלת דו"ח מלא ממקורות פתוחים.

המערכת שואבת נתונים ישירות ממאגרי משרד התחבורה ב-[data.gov.il](https://data.gov.il) (בלי תלות בצד ג' כמו דו"ח בלקר).

## מטרות
- כלי פשוט ומהיר לרוכשי רכב פרטיים ולסוחרי רכב.
- דו"ח בזמן אמת עם: מספר ידיים, בעלות חברה/ליסינג/השכרה, ק"מ אחרון, תוקף טסט, ריקולים, סטטוס פעיל.
- שאיבה ישירה מהמקור הממשלתי הפתוח.
