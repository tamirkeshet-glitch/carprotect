# ארכיטקטורה — CarProtect

## שכבות
```
[Mobile App]
   ↓ OCR + UI
[Backend API]
   ↓ שאילות מקבילות + Cache
[data.gov.il CKAN API]
```

## Backend (FastAPI מומלץ)
- Endpoint: `GET /vehicle/{plate}`
- שולף מקביל מ-4 מאגרים עיקריים
- מנרמל:
  - ספירת ידיים
  - דגל `had_company_ownership` (חברה / החכר / השכרה / סוחר)
  - ק"מ אחרון + תאריך
  - סטטוס פעיל
- Cache Redis (TTL 24h)
- החזרת JSON מבונה

## Mobile
- מסך סריקה גדול
